
# Lions Data Analysis

埼玉西武ライオンズに関するデータ分析をまとめたリポジトリです。
Pythonを用いて選手の成績や試合内容を分析し、データの可視化を通じて野球に関する考察を行っています。

## Analysis

### 1. ネビン選手の月別打撃成績
月別の打撃成績を可視化し、シーズン中の成績推移を分析しています。

### 2. 渡邊投手のマダックス達成試合の分析
投球数やアウトの種類などを分析し、試合内容を振り返っています。

### 3. 高橋投手の投球分析
球種・球速・投球位置などのデータを用いて、投球内容を分析しています。

## Tools
- Python
- pandas
- matplotlib

## Data Sources
各分析で使用したデータの出典は、分析ごとに記載しています。
